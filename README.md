# 반가운교회 홈페이지

React와 Vite로 만든 반가운교회 소개 홈페이지입니다.

## 시작하기

```sh
npm install
npm run dev
```

## 관리자 게시판 권장 구성

현재 웹사이트에는 공개 회원가입이나 게시글 작성 기능을 열지 않았습니다. 교회 소식 게시판을 운영할 때는 Firebase Authentication의 이메일/비밀번호 로그인을 켜고, 관리자가 직접 만든 계정만 사용하도록 하세요. 가입 UI 없이 관리자 계정을 Firebase 콘솔에서 생성하고, Firestore 문서의 `authorUid`와 인증된 UID를 확인하는 Security Rules를 적용하는 구성을 권장합니다. 소식 읽기는 공개, 생성·수정·삭제는 허용된 관리자 UID에 한정해야 합니다. Firebase 설정값은 브라우저에 공개되므로 보안 경계로 간주하면 안 됩니다.

게시판 공개 전에 Firebase Console에서 Authentication, Firestore, 앱 도메인 허용 목록, 비용 알림을 설정하고 실제 Security Rules를 배포해야 합니다. `src/firebase.js`에는 앱 연결만 준비되어 있습니다.

## 교회 운영 정보 확인 제안

- 성전 사진, 예배 공간과 다음세대 모임 사진을 촬영해 임시 그래픽을 교체하면 처음 방문하는 분들에게 공간을 더 잘 안내할 수 있습니다.
- 대중교통/주차 안내, 엘리베이터·유아 동반 정보, 새가족 문의 연락처와 개인정보 처리방침을 보완하면 방문 준비가 쉬워집니다.
- 설교 영상이나 주보를 게시할 계획이면 저작권과 게시 주기를 정한 뒤 소식 메뉴에 추가하는 편이 좋습니다.
